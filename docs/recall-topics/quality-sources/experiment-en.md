# Reading a small experiment

Twenty volunteers used interface A, and a separate group of twenty volunteers used interface B. The groups were not randomly assigned. The observed median task time was lower for group B.

The measured result describes these participants and this task. It does not by itself establish that interface B caused the difference, that every participant was faster, or that the same difference would occur for other tasks.

A follow-up could randomly assign participants to interfaces while holding the task and measurement procedure constant. The original observation is a reason to test this hypothesis, not a substitute for the follow-up.
