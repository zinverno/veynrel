## Default-model migration

| Stored configuration | Result |
| --- | --- |
| New installation, or old data with no Rerank block | Off / manual / Voyage / empty independent key |
| Disabled Rerank, absent model | Manual / Voyage; no request is sent |
| Enabled Rerank, absent model and mode | Automatic / Cohere, preserving its previous effective model |
| Enabled Rerank, explicit Cohere or custom ID | Same model and key; automatic when mode was absent |
| Disabled Rerank with explicit model | Same model and key; manual when mode was absent |
| Explicit manual or automatic | Same mode, regardless of enablement |
| Empty or invalid model string | Preserved; configuration validation blocks HTTP without substituting a provider |

The placeholder follows the default. Selecting Voyage does not supply a key or automatically connect. Existing save-queue rollback, index identity and settings/source/index invalidation tests remain enabled. The new regression matrix failed before the default change and then passed through both the merger and real plugin settings loader.

## Limits and remaining gates

This is Linux desktop/default-theme evidence. **MOBILE, screen readers, other operating systems and custom themes: NOT RUN.** Narrow desktop emulation is not mobile acceptance; minimum-version metadata is preserved, but Obsidian 1.8.7 itself was not run. No independent quality evaluation was added. Historical Rerank evidence remains in #73/#74; historical Decisions evidence remains in #71 with its documented errors and confidence limits.

The bounded benchmark does not justify guaranteed search improvement: 11 improved / 11 unchanged / 2 regressed, with relevant baseline top-1 already 23/24. Decisions is an experimental manual-review hint, with no automatic merge/delete/Findings update or confidence threshold.

Publication still requires maintainer review of this PR and the Community Review branch, approval to merge, exact merge-commit CI/build verification, and a separate explicit publication approval. Preparation does not authorize any of those actions.
