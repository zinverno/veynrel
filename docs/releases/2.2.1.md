# Veynrel 2.2.1

## English

- **Review vault:** a list first, with New/Reviewed queues and persistent **Leave as is** decisions tied to exact saved Markdown versions. The optional map opens explicitly. Changed content reopens eligibility; a link does not erase semantic overlap.
- **From recommendation to change:** separate AI consent, source-bound evidence, one main recommendation, action preflight, parameters and exact review. Supported consolidation routes keep separate Apply, History and Undo, stale-data checks and recovery guards. Merge/Group/Bundle describe their actual scope; selected-fragment copying is not automatic full-file merging.
- **Connection rules:** suppress connections within a tag/folder group or exclude that group from connection search, before top-K. Exercises can still connect to explanations; duplicate discovery is preserved.
- **Processing:** single-note atomization now uses a picker, AI consent, individual previews/exclusions and exact write confirmation. Source content remains; collisions, stale input and partial writes are reported. All editor/command entrances share the route. MOC generation requires preparation and confirmation of destinations, writes and any model requests. Batch retains its own selection.
- **Workspace polish:** Home reveals additional folders, Recall has clearer review/inventory/creation sections, and map expansion, navigation and RU/EN light/dark layouts are more consistent. No FSRS or ranking redesign.
- **Compatibility:** includes the official Review fixes from #118. Reported unnecessary assertions and CSS `:has()` are removed; the documented streaming `fetch` advisory remains.

Semantic map/connection calculation remains limited to **500 eligible documents per scope**; a larger inventory is not full semantic coverage. Models are optional external services and may charge: review the actual recipient and content before consent. Synthetic loopback checks validate integration, not live-model quality. Generative atomization and MOC **do not offer universal Undo**; partial writes are reported, and backups remain necessary. Rules/decisions have no multi-process or Sync conflict-resolution guarantee.

Plugin ID stays `ai-knowledge-hub`; compatibility stays Obsidian 1.8.7+, desktop and mobile. Runtime code is type-checked against the official 1.8.7 API. Native validation is Linux / Obsidian 1.13.7; physical mobile, Windows/macOS, screen readers and native 1.8.7 are unverified. Beta 2.2.0's narrower distribution metadata is not copied into stable.

## Русский

- **Разбор хранилища** открывается списком. «Новые / Рассмотренные» разделяет очередь и сохранённые решения «Оставить как есть» для конкретных версий Markdown. Изменение текста снова допускает пару к разбору. Карта открывается отдельно; добавленная ссылка не означает устранение смыслового пересечения.
- **Рекомендация ведёт к подготовке действия:** отдельное согласие на анализ, проверенные основания, предварительная проверка доступности, параметры и точный review. Apply, история и Undo остаются отдельными действиями. Merge/Group/Bundle честно показывают эффект: копирование выбранных фрагментов не является автоматическим слиянием целых файлов.
- **Правила связей** по тегу или папке работают до top-K: можно убрать «упражнение ↔ упражнение», сохранив «упражнение ↔ объяснение» и поиск дубликатов, либо полностью исключить группу из предложений связей.
- **Обработка:** атомизация одной заметки проходит выбор, согласие, просмотр и исключение предложений, отдельное подтверждение записи. Оригинальный текст сохраняется; устаревший источник, коллизии и частичные ошибки показаны явно. Команда и меню редактора используют тот же маршрут. MOC требует подготовки и подтверждения записи и запросов. Массовая обработка сама управляет выбором заметок.
- **Полировка:** доступ ко всем папкам на главной, структурированный экран повторения, исправления раскрытия карты, навигации и RU/EN в светлой/тёмной теме. FSRS и ранжирование не переделаны. Включены исправления официального Review #118; сохранено только обоснованное предупреждение streaming `fetch`.

Ограничения: семантический охват — **500 подходящих заметок в выбранной области**; внешние модели могут быть платными. Локальные синтетические ответы проверяют интеграцию, а не качество live-модели. Генеративная атомизация и MOC **не имеют универсального Undo**; частичные записи требуют внимания и резервной копии. Конфликты Sync/нескольких процессов не разрешаются автоматически. Проверена Linux desktop-среда; физический mobile, Windows/macOS, screen reader и native-запуск на Obsidian 1.8.7 не подтверждены.
