# Veynrel 2.3.0

**Stable release.**

Veynrel keeps its workspace for vault health, connections and Recall, and adds Studio for deliberate work on selected notes.

## What changes for users since 2.2.1

- **Reusable note recipes:** Smart Formatting, Training Journal and Nutrition Journal, plus validated local recipes. Select saved notes, inspect the outgoing request and review each result before writing.
- **Separate results by default:** create a Markdown result with a source link. It is not a clone with source frontmatter. Explicit source changes preserve supported YAML literally and use guarded Apply/Undo.
- **Community library:** inspect and install versioned recipes independently of running them. Updates are explicit and local edits are visible.
- **Editable diagrams:** generate a structure or flowchart, inspect it, then create native Excalidraw shapes, text and bound arrows. First open fits the drawing once and keeps source attribution separate from graph content.
- **Clearer review and native styling:** retained workflow drafts, lexical preservation observations, stricter diagram responses, distinct failure states and native theme controls. No automatic model repair or retries.

## Install or update

Use Obsidian's Community plugin update when offered, or download `main.js`, `manifest.json`, `styles.css` from [Veynrel 2.3.0](https://github.com/zinverno/veynrel/releases/tag/2.3.0). Back up first. Replace only those runtime files in `<vault>/<configDir>/plugins/ai-knowledge-hub/`; preserve `data.json`, indexes, Recall state and journals. Restart Obsidian.

Plugin ID, MIT license, author and minimum Obsidian 1.8.7 remain unchanged. Local Health and authored-card Recall need no LLM. Configure the language model separately for Studio, and embeddings for semantic discovery.

## Prerequisites and limits

Diagrams require Excalidraw **2.29.0** and verified structured-output capabilities on **public OpenRouter**. Markdown provider support does not imply diagram support. Model charges and retention are provider-specific; timeout/cancellation may still be billed.

Similarity is not proof of duplication. Local lexical checks and valid JSON do not verify factual accuracy. New Markdown notes and diagrams have no automatic delete/Undo. Other tools retain their operation-specific recovery contracts. Journals can contain plaintext note content; keep backups.

Native validation covers a disposable synthetic Linux vault, EN/RU and built-in light/dark; it does not establish physical mobile, every OS/theme or screen-reader support. Workflow media uses controlled responses, not a real-model benchmark. Historical host/zoom exceptions are not claimed fixed. Two deliberate fetch advisories remain; no zero-findings or full Stylelint claim.
