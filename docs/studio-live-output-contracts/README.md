## Runtime changes

| Area | Behavior |
| --- | --- |
| `api.ts` | Typed, opt-in structured output; existing buffered transport and 30-second inference timeout retained. Legacy callers keep their exact bodies, sampling and routing. Other connections cannot receive the new fields through this option. A separate credential-free public metadata GET uses the same buffered request primitive with a bounded 10-second wait. |
| `studio/diagram/spec.ts` | Canonical JSON Schema and local validator share required keys, enums, ID pattern and limits. Every edge requires a label. Local checks retain bounded raw/depth/strings/counts, prohibited control characters, global ID uniqueness, existing endpoints and selected kind. No repair of missing labels or branch conditions. |
| `studio/diagram/capabilities.ts` | Lazy explicit preflight for the selected model on exactly `https://openrouter.ai/api/v1`. Requires endpoint-level `structured_outputs`, `response_format` and all existing request parameters. Deterministic lexicographic compatible tag selection; a tag prefix is allowed only if every matching metadata row is compatible. No hardcoded model/provider. Memory cache: at most eight model entries, five minutes; no persisted discovery or passive refresh. |
| Diagram preparation / consent | The action explicitly discloses the credential-free model-ID metadata lookup. A compatible endpoint tag, `response_format.json_schema.strict=true` and `provider.only/order`, `require_parameters=true`, `allow_fallbacks=false` are in the exact frozen body. Expired capabilities or changed model/connection require fresh preparation and consent. No prompt-only fallback. Generic structural/decision examples are valid graphs and are not based on D/E facts. |
| Studio errors | Timeout, abort, HTTP, network, malformed envelope and local graph errors remain distinguishable via safe categories. No private transport message is exposed. Timeout explains that no note/drawing was changed by that request, remote generation/billing may continue, and late results are ignored. No retry or global timeout increase. |
| Builtins | IDs unchanged, three modified versions advance from 1.0.0 to 1.0.1. Training separates duration/repetitions/weight and preserves qualifiers, relative time and attribution. Nutrition distinguishes facts from quotations/examples and disallows quoted totals or unsolicited lookup/advice. Formatting clarifies useful structural changes and permits legitimate no-ops. Old user copies remain byte-identical. |

The local [meeting candidate and paired corpus](../../studio/evaluation/README.md) are evaluation material only. Published 1.0.0, catalog index/hash, installed provenance, Recipe v1 and existing Apply/Undo/create-only guards are unchanged. There is no new calculation engine, verifier, database or dependency.

The metadata advertises support; it does **not** prove provider enforcement or semantic accuracy. No verified capability path exists yet for other OpenRouter hosts, proxies or other providers, so diagram generation explicitly refuses them. Markdown Studio keeps its existing provider support. Endpoint metadata can change after preflight; `require_parameters` plus no-fallback routing constrains dispatch, and the local validator remains authoritative.

Official contracts checked on 2026-10-29: [structured output](https://openrouter.ai/docs/guides/features/structured-outputs), [routing and slug matching](https://openrouter.ai/docs/guides/routing/provider-selection), [endpoint metadata](https://openrouter.ai/docs/api/api-reference/endpoints/list-all-endpoints-for-a-model). Public anonymous metadata failure is a supported refusal state; there is no credentialed fallback.
