# Читаемость главных действий — PR #125

Точечное продолжение theme-fidelity, без нового редизайна. Единственный изменённый
runtime-файл — `styles.css`. Engine, prompts, guards, Apply/Undo, журналы и сайт не менялись.

## Изменение контракта кнопки

Главные действия Health/Studio и принадлежащих Veynrel подтверждений используют
`--text-normal` на `--interactive-normal`, при hover — `--interactive-hover`.
Приоритет передают также начертание `--font-semibold` и рамка `--text-muted`.
Фокус — отдельная сплошная рамка 2px из `--text-normal`, отступ 3px.
Она видна при **любом** фокусе: после возврата из native modal Chromium иногда
оставляет сфокусированную кнопку без `:focus-visible`. Это не повод скрывать фокус.
Размер текста не увеличен ради снижения порога.

Прежнее требование совпадать с залитой native `mod-cta` заменено явно:
совпадение с **нейтральными** семантическими токенами проверяется отдельно от
неизменённого порога текста **4.5:1**. Цвета native accent-кнопки остаются в отчёте
для сравнения, но не дают PASS читаемости. Фон Health/Studio, accent, theme и snippets
не меняются. Нет фиксированного белого/чёрного текста и универсального перекрашивания.
Несвязанный Pair Inspector сохранён как в исходном PR.

## Метод проверки

`studio-theme-native.mjs`: Default / Minimal 8.2.2 / Red Graphite 1.0.5,
light/dark, акценты `#7c009e` и `#087f8c` — 12 сочетаний.
Реальные активные Health action, Studio create-review и modal confirm проверяются
в normal/hover/focus: 108 измерений. Hover вызывается указателем, для фокуса
используется клавиатурная модальность и фокус реального элемента. Проверяются
активный элемент, видимая рамка, толщина, отступ и контраст рамки >=3:1.
Кнопка подтверждения при измерении **не нажимается**; snapshot и число запросов
должны остаться прежними. Отдельный Diagram-прогон проверяет настоящее создание.

Computed RGB/RGBA сохраняются полностью. Прозрачная поверхность Minimal
композируется поверх фактических computed ancestor backgrounds; непрозрачный
предок обязателен. Значения и сравнение с порогами не округляются.
Токены поверхности/текста/полей Health и Studio проверяются независимо.
Это ограниченная проверенная матрица, не гарантия для произвольно неконтрастных тем.

## Renderer exception: статус расследования

Предыдущий и один повторный полный Markdown-прогон зарегистрировали:

```
TypeError: t.webContents.getZoomFactor is not a function
    at e.updateStatus (app://obsidian.md/app.js:1:1516930)
    at c (app://obsidian.md/app.js:1:545776)
    at u (app://obsidian.md/app.js:1:545888)
```

Полный сценарий воспроизведения: `scripts/studio-native.mjs` — подготовка и
Review/Apply/Undo, два сохранённых редактора одного файла, native popout,
отказ Apply при открытом popout, закрытие popout, повторный Apply/Undo,
переключение маршрутов/тем/размеров, zoom 2 и обратно 1. Полный стек сохранён
в evidence; наличие `app.js` **не доказывает** независимость от Veynrel.

`scripts/obsidian-zoom-repro-native.mjs` выполняет парный минимальный сценарий
на одинаковых синтетических заметках в отдельных профилях **без** Veynrel и
**с** Veynrel: main zoom 2/1/2/1, открыть native Markdown popout, повторить zoom,
активировать и закрыть popout, повторить zoom 2/1; с плагином дополнительно Studio.
Оба варианта завершились без исключения. Минимальный сценарий не воспроизвёл
дефект; причина и независимость не установлены. Последний полный Markdown-прогон
также не воспроизвёл его. Ошибка **не объявляется исправленной**.
Никакого monkey-patch, глобального подавления или изменения Obsidian нет.
