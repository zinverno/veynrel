# A mirror for two working folders

Bidirectional synchronization aims to make two active folders agree. Deletions and renames propagate according to its conflict rules. This is convenient for continuing work on another machine but can spread an accidental removal to both sides.

Some products retain versions, yet that must be checked separately from the fact that synchronization succeeds. A green status means the mirror is current, not that historical files are recoverable. Keep conflicts visible and choose a separate backup policy when old states matter.
