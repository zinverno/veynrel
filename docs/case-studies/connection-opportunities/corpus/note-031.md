# Срок жизни ответов DNS

Рекурсивный сервер сохраняет ответы на ограниченное время. Отрицательный ответ о несуществующем имени тоже может попасть в кеш. Поэтому запись, созданная после неудачного запроса, иногда становится видна не сразу.

Сравните ответ авторитетного сервера с ответом используемого резолвера. Повторное сохранение уже правильной записи не очищает чужой кеш. Успешный ответ из другой сети помогает локализовать проблему, но сам по себе не доказывает, какой именно кеш задерживает обновление.
