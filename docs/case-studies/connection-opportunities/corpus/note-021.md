# Off-site version history

An object store can retain previous versions after a file is overwritten or deleted. This protects against losing the local machine, provided credentials, retention and restore procedures are sound. Upload bandwidth and storage charges belong in the plan.

The workflow intentionally transfers files to a remote system. It does not meet a requirement that every backup stay on local disks. Encryption before upload changes confidentiality, not location. Test how a deleted object version is recovered before relying on the service.
