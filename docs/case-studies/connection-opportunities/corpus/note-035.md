# Несколько потоков поверх QUIC

QUIC использует UDP как транспорт для защищённого соединения и предоставляет приложению отдельные потоки. Потеря данных одного потока не требует останавливать доставку уже доступных данных другого. Это отличается от общего упорядоченного потока байтов TCP.

Потери всё равно требуют восстановления, а управление перегрузкой остаётся общим ограничением. Переход на новый протокол не исправит медленную обработку на сервере. При измерениях разделяйте установление соединения, передачу и время приложения.
