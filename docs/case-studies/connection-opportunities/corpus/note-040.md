# Keeping a backup out of the failure domain

A disk permanently attached to the same writable system can be damaged by the same mistake or malicious process as the source. Rotate an offline local copy and retain several dated generations. Disconnect it after verification so ordinary deletions cannot immediately propagate to every copy.

This improves isolation but is not proof that the files can be restored or decrypted. A separate recovery rehearsal checks that. Decide how much recent work may be lost between rotations, label the generations, and inspect disk health without treating health statistics as a substitute for reading the data.
