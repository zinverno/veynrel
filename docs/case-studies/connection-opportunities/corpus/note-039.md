# A restore rehearsal

Choose a dated backup generation and recover several files into an empty scratch directory. Compare their bytes or checksums with the expected versions, then open the formats people actually use. Test an accidentally deleted file as well as a current one.

Record elapsed time, missing tools and every manual step needed to locate the right generation. A scheduled backup job reporting success is only evidence that the job ran. Recovery instructions should be understandable on a replacement machine. Never rehearse by overwriting the working originals.
