# Лента, которая растёт между страницами

Номер страницы со смещением плохо подходит для списка, куда постоянно добавляют записи в начало. Новые строки сдвигают границы, поэтому следующая страница может повторить уже прочитанное. Передавайте курсор из последнего увиденного времени и уникального идентификатора, а следующую порцию выбирайте строго после этой пары в том же порядке.

Уникальный второй ключ нужен при одинаковом времени. Курсор должен сохранять фильтры и направление сортировки. Такая пагинация не обещает неизменный снимок всей базы: для согласованного экспорта потребуется отдельная граница снимка или версия набора.
