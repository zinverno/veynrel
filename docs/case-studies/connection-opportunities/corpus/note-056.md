# Compressing a collection for transfer

An archive preserves a collection of paths while compression reduces repeated byte patterns. Already compressed photographs often shrink little. Choose a format that the receiving machine can open and verify the archive checksum after transfer.

Compression is not encryption or version history. Removing originals immediately after creating an archive eliminates an independent copy. Test extraction into an empty directory and check how the tool handles unusual filenames. A smaller file is useful only if its contents remain recoverable.
