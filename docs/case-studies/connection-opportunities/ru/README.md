# Русскоязычный опыт: пробные переводы

**Этап 1, ожидается обратная связь автора.** Подготовлены пять черновых переводов
из 40 заметок. Это материал для оценки языка и предметной области, а не новый
семантический эксперимент. Остальные 35 заметок пока не переведены; новых
embeddings, кандидатов, пользовательских оценок и скриншотов здесь нет.

## Источник и границы

Основа — публичный синтетический корпус в [../corpus/](../corpus/), лицензия
репозитория MIT. Исходная версия зафиксирована коммитом
`2ae9a19e80524131a15bd78dba91ff2b7f34f78f`. Тексты описывают учебные ситуации,
а не опыт автора или содержимое его личного хранилища. Переводы подготовлены
агентом; автор ещё не оценивал их стиль.

[Исходный опыт](../index.md) остаётся отдельным baseline со смешанным языковым
составом. Его корпус, векторы, наблюдения и изображения не изменены и не являются
результатами русскоязычного опыта. Корневые скрипты воспроизведения пока работают
только с этим baseline.

Выбор даёт короткие практические заметки и один длинный текст с lease и fencing.
Это выбор образцов для обсуждения перевода, **не отбор кандидатов** будущего
опыта. Пары из этих заметок уже встречались в baseline: последующую оценку автора
нельзя будет называть слепой или независимой от знакомства с исходным опытом.

Сохранены имена файлов, разделы, порядок механизмов и оговорки. У этих пяти
исходных заметок нет исходящих Markdown-ссылок; в переводах их тоже нет.
Входящие ссылки определяются остальным корпусом, который пока не переведён.
При подготовке полного корпуса нужно сохранить все семь исходных направленных
ссылок из [протокола baseline](../protocol.json), не добавляя связей ради опыта.

Перевод различает сохранение дорогого прогресса и пересоздание дешёвого
результата, зеркало и поколения копий, изоляцию и проверку восстановления,
истечение lease и проверку fencing на стороне ресурса. Технические термины
оставлены там, где русский пересказ мог бы скрыть важный механизм.

## Следующий шаг зависит от автора

Нужна оценка естественности языка и интереса к предметной области. После ответа
можно уточнить подачу и закончить перевод. Любые содержательные изменения сверх
перевода нужно будет отметить отдельно как ограничение сравнения с baseline.

До этого новый расчёт не запускается. Для русского текста потребуются новые
embeddings; векторы исходных текстов не подходят. Выбор модели и воспроизводимая
конфигурация относятся к следующему этапу. Платные запросы требуют отдельного
согласия автора.

Пользовательские оценки найденных связей появятся в репозитории только после
их получения и одобрения автором для публичного использования. Техническая
интерпретация не заменяет эти оценки. Сам Veynrel не создаёт ссылки автоматически;
Useful / Not useful / Unsure хранятся только в сессии интерфейса и сбрасываются
при новом снимке сравнения.

Сверка с оригиналами подтвердила неизменность frontmatter, исходящих ссылок и
числа разделов у пяти текстов. Все локальные ссылки этой страницы разрешаются.

и `npm run build` прошли; build выполнен в составе lint. В lint осталось прежнее
предупреждение о `fetch` в `api.ts:402`, ошибок нет. Эти проверки не оценивают
естественность перевода и не являются испытанием русского корпуса в Obsidian.
