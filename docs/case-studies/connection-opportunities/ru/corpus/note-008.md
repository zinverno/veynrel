# Когда сборку проще начать заново

Предпросмотр документации собирается во временном каталоге. Если компиляция завершилась с ошибкой, каталог можно удалить и повторить сборку из чистых исходных данных. Пользовательских правок в нём нет, а результаты легко получить заново. Это избавляет от сложного восстановления частично выполненной сборки.

Такой подход не годится для ночной конвертации, если повторное создание готовых файлов обходится дорого. Для сборки стоит записывать в журнал ревизию исходных данных и версию компилятора. Успешная сборка атомарно заменяет опубликованный предпросмотр, поэтому посетители не увидят недописанную страницу.
