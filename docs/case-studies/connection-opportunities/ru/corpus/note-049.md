# Как выбрать единственный планировщик

Обычную работу должен раздавать один активный планировщик. Lease и периодический heartbeat позволяют выбрать замену, если старая машина исчезла. Короткий срок ускоряет переключение, но чаще принимает долгую паузу за отказ.

Истёкший lease меняет право выдавать новые задания. Старый процесс от этого физически не остановится и может проснуться позже. Здесь пока только выбор лидера и наблюдение за ним. Механизм отклонения его старых записей на стороне хранилища в этой схеме не описан.

Переключения должны быть видны в журнале. Порядок прихода логов и показания часов сами по себе не доказывают, кто действовал первым. Нужно отдельно разобраться с записью результатов после смены лидера.
