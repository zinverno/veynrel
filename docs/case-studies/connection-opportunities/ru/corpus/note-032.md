# Список запусков растёт между страницами

OFFSET неудобен, если новые запуски постоянно появляются в начале списка. Границы сдвигаются: на следующей странице можно снова увидеть уже прочитанное.

Вариант — курсор из времени и уникального ID последней строки. Следующую порцию выбирать строго после этой пары в том же порядке. Второй ключ нужен, когда время совпало. Фильтры и направление сортировки тоже часть курсора.

Это решает смещение позиций, но не делает всю базу неизменной. Для выгрузки обучающего набора из изменяемых записей понадобится ещё граница снимка или версия данных. Не хочется обещать экспорт той же ручкой, которой листается живая лента.
