# Номера страниц всё ещё бывают удобны

Для маленького фиксированного отчёта LIMIT и OFFSET понятны: можно сразу открыть страницу с номером. База пропускает строки до смещения и отдаёт порцию. На больших смещениях цена может стать заметной.

Если перед текущей страницей появляются новые записи, между запросами будут повторы или пропуски. Уникальная сортировка убирает неоднозначные равенства, но не мешает позициям двигаться.

Для отчёта по уже зафиксированному снимку нумерация остаётся разумным вариантом. Сначала определить, это живой список или готовый отчёт, а потом выбирать механизм пагинации.
