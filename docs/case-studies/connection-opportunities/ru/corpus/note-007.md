# Как сохранить прогресс пакетной конвертации

Конвертер изображений обрабатывает каталог за ночь. Каждый готовый результат он сначала записывает во временный файл, проверяет, затем переименовывает. После этого надёжно сохраняет контрольную точку: контрольную сумму исходного файла и границу завершённой обработки. При перезапуске конвертер проверяет уже записанные результаты и продолжает с последней зафиксированной границы, а не обрабатывает весь каталог заново.

Контрольная точка должна соответствовать сохранённым файлам. Если продвинуть счётчик раньше, чем файл будет надёжно записан, после отключения питания часть работы можно пропустить. Такой подход рассчитан на локальные преобразования, которые можно повторить. Если пропал ответ на внешнюю платную операцию, нужно найти подтверждение её выполнения у внешней системы. Одна локальная контрольная точка не позволяет установить, состоялась ли эта операция.
