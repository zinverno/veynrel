# Ссылка на файл не создаёт вторую копию

Hard link даёт ещё одно имя тем же данным внутри файловой системы. Изменение через любое имя меняет общий файл. Symlink хранит путь, который разрешается при обращении; после переноса цели он может сломаться.

В снимках на жёстких ссылках готовые поколения должны быть неизменными. Иначе исправление одного файла заденет то, что считалось старой версией. Ни один из этих видов ссылок сам по себе не является независимым backup.

Симлинк на точку монтирования также не доказывает присутствие нужного диска. Перед выбором раскладки данных разобраться, где находится идентичность: в пути, файле или томе. Иначе внешне похожие ссылки будут обещать разное.
