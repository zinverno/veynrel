# После JOIN примеров стало больше

Допустим, у каждого обучающего примера может быть несколько записей разметки. JOIN по ID примера размножит строки. Таблицы по отдельности могут быть корректны; неожиданное число строк появляется из выбранного отношения.

Перед подсчётом метрики определить, на каком уровне она нужна: пример, отдельная аннотация или что-то ещё. Индекс ускорит поиск, но неверное условие соединения не исправит.

Проверить маленький пример вручную. DISTINCT в конце может скрыть увеличение числа строк и оставить неправильный расчёт. Пока не ясна ожидаемая кратность отношения, называть результат дублями рано.
