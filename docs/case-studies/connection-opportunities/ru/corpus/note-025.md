# Короткое решение под блокировкой строки

SELECT FOR UPDATE удерживает блокировку строки до конца транзакции. Конфликтующий писатель ждёт или получает ошибку по правилам таймаута. Подходит, когда надо быстро прочитать общее состояние и сразу изменить его.

Для выдачи задания это может быть короткая критическая секция. Для формы, в которой человек несколько минут выбирает параметры, — уже плохая граница транзакции. Долгие блокировки повышают конкуренцию и могут участвовать в deadlock.

Таймаут блокировки не означает успешного обновления. Сначала определить длительность операции и кто именно принимает решение. Если внутри есть человеческое ожидание, понадобится другая стратегия конкурентного редактирования.
