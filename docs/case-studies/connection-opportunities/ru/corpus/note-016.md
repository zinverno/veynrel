# Индекс для списка запусков в PostgreSQL

Если список запусков тормозит, сначала нужен реальный запрос и его план. Индекс по колонкам «на всякий случай» увеличит место и работу при записи, а нужный запрос может не ускорить.

CREATE INDEX CONCURRENTLY позволяет строить индекс с меньшими помехами обычным записям. За это — дополнительная работа и ограничения на транзакции. После неудачного построения может остаться невалидный индекс: его надо проверить, а не считать операцию незаметно отменённой.

После выкладки снова посмотреть план. Это решение про путь доступа в PostgreSQL; к режиму журналирования SQLite оно отношения не имеет. Пока нет конкретного медленного запроса, выбирать состав индекса рано.
