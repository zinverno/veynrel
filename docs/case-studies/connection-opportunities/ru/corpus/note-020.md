# Синхронизация рабочей папки с разметкой

Удобно продолжить разметку на другом компьютере и увидеть ту же папку. Двусторонняя синхронизация переносит изменения, переименования и удаления по своим правилам конфликтов.

Вот с удалениями и проблема: ошибку можно аккуратно разнести на обе машины. Зелёный статус показывает, что папки согласованы, а не что вчерашнее состояние получится вернуть.

У некоторых инструментов есть история версий, но её надо проверить отдельно. Конфликты не прятать. Если старая разметка нужна для воспроизведения запуска, политика хранения прежних состояний должна быть самостоятельным решением.
