# Ключ провайдера не должен попасть в конфиг запуска

Локальный процесс может прочитать секрет из файла с ограниченным доступом или получить через окружение. В аргументах команды, исходниках и логах значения быть не должно. Для диагностики достаточно показать, удалось ли его загрузить.

Переменная окружения не шифрует секрет. Дочерние процессы могут унаследовать её, локальная инспекция — увидеть. Поэтому ограничить время жизни процесса и убрать ненужное наследование.

Для проверки внешнего API подходят синтетические входы. Это уменьшает риск раскрыть личные данные, но не делает платный запуск бесплатным. До проверки нужны отдельные условия отправки и оплаты. Здесь сами вызовы не выполнялись.
