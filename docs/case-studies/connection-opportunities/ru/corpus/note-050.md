# Подключить ещё один диск для данных

Для нового тома сначала создать точку монтирования и подключить нужную файловую систему. Потом уже копировать файлы. В конфиге удобнее устойчивый ID файловой системы: имя устройства может измениться после перезагрузки.

Место и права проверить маленьким временным файлом. Форматирование уничтожает прежнюю файловую систему — это шаг первоначальной подготовки, а не обычного восстановления старого диска.

Остаётся другая задача: что делать уже работающему каталогу, если ожидаемый диск пропал. Эта заметка её не решает. Существующая папка точки монтирования ещё не говорит, какой том к ней подключён.
