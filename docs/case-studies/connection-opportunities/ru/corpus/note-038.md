# Копия зашифрована. Получится её открыть?

Для восстановления нужен секрет, который не пропадёт вместе с основной машиной. Его резервная копия хранится отдельно. В чистом тестовом окружении должна работать именно записанная процедура разблокировки.

Успешное копирование или загрузка файла не доказывает, что архив расшифруется. Нужна небольшая, но характерная выборка: имя с кириллицей, недавно изменённый файл, разные используемые форматы. Восстановить отдельно, открыть, сравнить контрольные суммы.

Записать поколение копии. Проверка существования архива слишком слабая: нужен весь путь до читаемых данных. Ключи в журнал этой проверки не помещать. Здесь только план такого прогона.
