# Запуск отправлен, ответ потерялся

До отправки внешней задачи сохранить её стабильный ID и состояние «зарезервировано». Соединение закрылось после отправки — результат неизвестен. Это не доказательство, что обучение не началось или деньги не списались.

Сначала запросить подтверждение у провайдера по этому ID. Состояния «подтверждено», «ошибка до отправки» и «неизвестно» должны различаться. После перезапуска клиент читает журнал и не отправляет неопределённые операции заново автоматически.

Если у провайдера нет поиска по ID и гарантии идемпотентности, может понадобиться ручная сверка. Создать новый ID — значит спрятать неопределённость, а не устранить её. Конкретный контракт внешнего сервиса ещё нужно проверить.
