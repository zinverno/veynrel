# Очередь на GPU: три разных ограничения

Есть скорость входящих запросов, длина очереди и число одновременно работающих задач. Это разные ручки. Один лимит «не больше N» без пояснения легко настроить не туда.

Token bucket разрешает короткий всплеск, но ограничивает среднюю частоту. Запрос тратит токен; токенов нет — отказ или ограниченное ожидание. Квота на аккаунт нужна, чтобы один клиент не занял весь сервис.

Квоты не рассинхронизируют повторы после аварии. Планировать мощность придётся по потоку задач и времени обработки, а задержки повторов остаются у клиента. На графике нагрузки хочется отдельно видеть новые задания и повторные обращения. Конкретные лимиты без замера длительности обучения пока брать неоткуда.
