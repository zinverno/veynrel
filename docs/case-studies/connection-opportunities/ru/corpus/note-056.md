# Упаковать набор изображений для передачи

Архив сохраняет набор путей, сжатие сокращает повторяющиеся байты. Уже сжатые фотографии могут почти не уменьшиться. Формат выбирать с учётом того, что сможет открыть другая машина.

После передачи проверить контрольную сумму архива и распаковку в пустой каталог. Отдельно посмотреть необычные имена файлов. Удалить оригиналы сразу после упаковки — потерять независимую копию.

Сжатие не даёт ни шифрования, ни истории версий. Пока задача только в переносе набора. Нужен ли пароль и какие версии хранить — другие решения. Размер архива ещё не измерялся.
