# Для одного загрузчика хватит простого backoff

Загрузчик весов может ждать одну, две, четыре, восемь секунд после последовательных сетевых ошибок. Такое расписание легко проверять в тестах. Успех сбрасывает счётчик, после заданного числа попыток — остановка с последним статусом. Нужно явно определить, считаются ли в лимите первая попытка и ожидание после неё.

Для одного клиента нормально. Для одновременно стартовавшего парка контейнеров интервалы совпадут. Просто поднять максимальную задержку — снизить среднюю нагрузку, но оставить пики.

Здесь операция только читает данные. Файл сначала временный, переименование после проверки контрольной суммы. Для команды, которая что-то меняет на сервере, понадобится отдельное правило безопасного повтора.
