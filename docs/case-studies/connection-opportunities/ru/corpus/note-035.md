# Что дают отдельные потоки QUIC

QUIC работает поверх UDP и предоставляет защищённое соединение с отдельными потоками. Когда теряются данные одного потока, доставка уже доступных данных другого не обязана останавливаться. У TCP общий упорядоченный поток байтов.

Потери всё равно приходится восстанавливать. Управление перегрузкой остаётся ограничением для трафика. Медленный обработчик на сервере после смены протокола быстрее не станет.

Для проверки разложить задержку на установление соединения, передачу и работу приложения. Иначе любое изменение общей длительности легко приписать QUIC без достаточных оснований.
