# Повтор запроса не должен запускать второе обучение

Для платного запуска нужен ID операции ещё до первого POST. На сервере он связывается с хешем параметров и итогом. Тот же ID с теми же параметрами должен вернуть прежний результат, а не создать ещё одну задачу. Другие параметры под старым ID — ошибка.

Два намеренных запуска с одинаковым конфигом остаются двумя операциями. Сравнение тел запросов или файлов весов не заменяет их идентичность. ID должен переживать перезапуск клиента.

Если первый ответ потерялся, искать состояние по этому ID. Повторять отправку можно только в рамках явно описанного сервером контракта идемпотентности. Само наличие заголовка с красивым названием ещё не означает, что сервер его соблюдает.
