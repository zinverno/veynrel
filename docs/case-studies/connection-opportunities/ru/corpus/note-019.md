# На каком датасете это обучалось?

Папка `dataset/latest` удобна до первого вопроса про старый запуск. Если разметку в ней поправили, одно имя каталога уже не объясняет, какие данные видел тот запуск.

Черновой вариант: неизменяемые поколения данных, у каждого свой идентификатор и список файлов с контрольными суммами. Запуск ссылается на конкретное поколение. Старые версии удаляются по отдельному правилу хранения, а не вслед за удалением рабочего файла.

Для локальных снимков можно экономить место жёсткими ссылками на неизменившиеся файлы. Но тогда нельзя править файл внутри готового снимка на месте: данные могут быть общими с другими поколениями. Исправление разметки должно попасть в новую версию.

Синхронизируемое зеркало тоже может перенести удаление. Нужны поколения на отдельном диске и проверка восстановления в другой каталог; после копирования и проверки диск можно отключить.

Сам список контрольных сумм не восстановит потерянные файлы. И ещё надо решить срок хранения: старый запуск становится трудно повторить, если его данные уже удалены. Политика пока не выбрана.
