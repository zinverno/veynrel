# Локальные снимки на случай ошибочного удаления

Храните несколько поколений резервных копий с датами на отдельном локальном диске. Инструмент создания снимков может использовать жёсткие ссылки для неизменившихся файлов и сохранять прежние деревья каталогов. Удаление исходного файла не должно удалять его предыдущие версии из копий. Старые снимки удаляются только по явно заданному расписанию хранения.

Синхронизируемое зеркало обычно переносит и удаления, поэтому само по себе не поможет вернуть файл, случайно удалённый вчера. Проверьте восстановление в другой каталог и отключите резервный диск после завершения работы. Жёсткие ссылки экономят место только для неизменившегося содержимого: правка файла внутри снимка на месте может повредить общие данные. Готовые поколения копий должны оставаться неизменными.
