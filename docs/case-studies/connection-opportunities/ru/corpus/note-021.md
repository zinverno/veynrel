# Выносить историю артефактов в объектное хранилище?

Версии объектов могут сохранить прежние веса или данные после перезаписи и удаления. Это помогает при потере локальной машины, если не потеряны доступы и действительно настроены сроки хранения.

В цену решения входят загрузка по сети, место и восстановление. Пока нет оценки объёма, говорить «почти бесплатно» не из чего. Нужна проба восстановления конкретной удалённой версии.

По этой схеме файлы уходят во внешнюю систему. Если условие проекта — все копии только на локальных дисках, такой вариант не подходит. Шифрование перед отправкой меняет доступность содержимого для посторонних, но не место хранения.
