# Endpoint появился, а DNS всё ещё говорит NXDOMAIN

Резолвер кеширует и отрицательные ответы. Если сначала спросить о несуществующем имени, а потом создать запись для сервиса, этот резолвер может продолжать отвечать NXDOMAIN до истечения отрицательного кеша.

Проверить авторитетный сервер отдельно от рекурсивного. Правильную запись бессмысленно сохранять снова и снова. Низкий TTL, выставленный уже после отрицательного ответа, не удалит ранее сохранённые кеши задним числом.

Есть ещё кеш ОС и браузера. Для сравнения проверок записывать время наблюдения и смотреть сведения об authority в ответе. Иначе два теста с разницей во времени легко принять за противоречие.
