# Удалили старые метрики, а SQLite не уменьшилась

Удалённые строки обычно оставляют страницы для повторного использования внутри файла. Поэтому размер на диске может не упасть, хотя записи уже исчезли.

VACUUM пересобирает базу плотнее. Ему нужно временное место и согласование с остальной работой. Это обслуживание файла, а не настройка совместной работы читателей и писателей.

Для журнала экспериментов сначала понять, мешает ли размер вообще. Пересборка ради красивой цифры может быть дороже свободных страниц. Автоматический vacuum тоже имеет накладные расходы. Backup и проверка целостности решают другие задачи; сжатый файл их не заменяет.
