зафиксированным JSON. В native-прогоне совпали **все 149 пар**, их категории,

путями, а не два независимых подтверждения полезности.

Известная связь `054 → 022` осталась Explicit-only: параметры credentials и
запуск внешнего задания связаны вручную, но не вошли в семантический top-5 union.
Это не доказательство плохой ссылки. Её точный cosine не вычислялся.

## Техническая интерпретация, не мнение автора

- RU02 позволяет обсудить контраст: сохранять дорогое состояние или пересоздать
  дешёвое производное. Цена пересчёта в учебных заметках не измерена.
- RU07 и RU08 повторяют значительную часть одного механизма. Такое совпадение
  ожидаемо; обнаружение нового знания здесь не установлено.
- RU04 объединяет операции вокруг изображений, но упаковка не решает ошибку
  удаления записей при отсутствующем диске. Необходимость прямой ссылки не ясна.
- RU05 объединяет конкурирующую работу на разных уровнях. Блокировка строки,
  lease планировщика и fencing хранилища не взаимозаменяемы. Связь без объяснения
  может ввести читателя в заблуждение.

Это варианты для обсуждения. Ни одна из этих формулировок не является
пользовательским Useful / Not useful / Unsure.

## Native и неполные данные

Настоящий Obsidian загрузил подготовленный новым расчётом локальный индекс.
Полное исходное embedding-вычисление выполнено Python на CPU **до** запуска
Obsidian; live-индексация текстов удалённым API в Obsidian не проводилась.
Внешний платный провайдер не использовался. Loopback endpoint допускает только
точные сохранённые входы и не имеет внешнего fallback.

17 native-проверок прошли: карта, полное сравнение, категории, три rank-фильтра,
поиск, Excalidraw, evidence, отсутствие побочных действий, частичные метаданные,
восстановление и открытие двух заметок. На пути карты/сравнения измерены нулевые
embed, read, cachedRead и Markdown write. Открытие заметок — отдельное действие
чтения после этого измерения. Все 40 файлов остались неизменными; verdicts не
выставлялись даже для проверки элементов управления.

При искусственном отсутствии метаданных заметки 019: сопоставимых заметок 39,
Candidate 128, Aligned 5, Explicit-only 1, неклассифицированных семантических
пар 15. Возврат метаданных восстановил исходные числа. Это контролируемая
инъекция, а не обнаруженная случайная неисправность хранилища.

Два снимка — текущая русская карта и RU01 с признаками. Они просмотрены визуально,
без масок и изменений интерфейса. Третий снимок не сделан: практическое действие
ещё не выбиралось автором. [Манифест](assets/manifest.json).

## Что остаётся неизвестным

Полезность для автора, необходимость ссылки и интересный для него пример ждут
ответов. Практический результат не заявлен. Нет выводов о точности на всех
заметках, других пользователях, личных vault, экономии времени или доходах.

Модель, язык, стиль и содержание изменены одновременно. Новый cosine нельзя
сравнивать с baseline как общую шкалу качества. В частности, 143 вместо 139
Candidate не означает улучшения. Max-sequence 512 отличается от стандартных
128 данной MiniLM; полный вход помещается, но качество длинных представлений
не подтверждено отдельным benchmark. Десятка выбрана по рангу, не случайно;
автор уже знаком с частью исходных заметок.
