# Contributing

> **2.4.0 release candidate.** Check the [published releases](https://github.com/zinverno/veynrel/releases/latest) for the stable download. The [2.3.1 guide](https://github.com/zinverno/veynrel/tree/2.3.1/docs/wiki) covers the earlier interface.

See the canonical [CONTRIBUTING.md](../../CONTRIBUTING.md) for build commands, module ownership, synthetic native testing and review expectations.

Public documentation is English. Translate actual product labels carefully; keep screenshot provenance and distinguish controlled-response workflows from real-model evidence. Recipes belong in the separate [catalog repository](https://github.com/zinverno/veynrel-recipes).
