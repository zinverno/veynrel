# Map Visual Reset v3 — visual review candidate

**Статус: кандидат для ручного визуального просмотра (контрольная точка A). UX не принят.** Пользователь отверг визуализацию v2 из #107 на `508c6ab32b08c2ade584b34ac4d804f08cdf4d93`. Старые зелёные тесты и native PASS этого не отменяют. Дальнейшая общая приёмка и этап B требуют явного одобрения изображения и поведения пользователем.

Отдельная экспериментальная ветка `experiment/map-visual-reset-v3` начинается от этого HEAD #107. Зависимая база #106 сохранена; main, чужие рабочие деревья и установленный TEST не заменяются. Версия и зависимости не меняются.

## Причины и новый контракт

В проверенной v2 клетки Вороного и отмена общих рёбер давали жёсткие границы. Текст находился в масштабируемой SVG-группе и массово появлялся после порога zoom; коллизии не проверялись. Зоны использовали accent/dash, кандидаты — вынесенные ромбы. Wheel-handler уже существовал.

V3 заменяет эту модель:

- Документы — небольшие точки постоянного экранного размера. Небольшой ободок на точке означает существующего кандидата; выбранная заметка предлагает «Разобрать». Это не подтверждение дубликата.
- Реальные ссылки — тонкие направленные линии, доступные semantic neighbors — пунктир. Прежние ограничения числа линий и точные источники сохранены.
- Теги — локальные мягкие радиальные пятна. Они могут пересекаться с чужими узлами: геометрия **не определяет членство**. Выбор/hover/focus тега выделяет только участников из metadata. Выбранный документ одновременно показывает цветовые сегменты активных принадлежностей и подчёркивает подписанные chips.
- Слои независимы от AND/OR-фильтров. Нет основной зоны. Сохраняются direct/inherited, known/unknown/stale, inline/frontmatter и до восьми активных слоёв. По умолчанию предложены три слоя разных доступных категорий по охвату; это подписанная эвристика, а не утверждённая классификация.
- Цвет закрепляется за точным tag ID в состоянии вида. При первом появлении оттенок отдаляется от уже активных цветов; reorder/toggle не перекрашивают ранее назначенный тег. Светлота/насыщенность адаптируются к вычисленному фону; подпись, подсветка и список дают альтернативу цвету. Гарантии для всех сторонних тем нет.
- Контролы и доступная раскрываемая помощь расположены по краю холста. Постоянная нижняя легенда удалена. Большая площадь, собственный expanded mode и оболочка Stage 1.1 сохранены.

Старые тесты про обязательный обход чужого центра контуром заменены контрактом «мягкое поле может пройти через посторонний узел, но metadata membership от этого не меняется». Safety/data tests не ослаблялись.

## Физика, камера и текст

`WorkbenchSimulation` содержит только UI-копии координат. Начальное расположение — детерминированная спираль с порядком по hash точного пути, без алфавитной решётки. На изменении набора данных неизменённые пути сохраняют координаты. Конечное охлаждение, отталкивание, link/semantic attraction, collision separation и мягкий центр работают до 500 документов. Вес используется прежним `edgeAttraction`; семантическое ребро без доступного score не создаёт силы. Теги не добавляют скрытых сил.

Один tick выполняется за кадр; нагрев происходит при изменении данных или drag, а не при hover, выборе, zoom или цветовых слоях. Перетаскиваемая точка фиксируется под указателем и освобождается при release/cancel/lost capture. После охлаждения RAF прекращается. В скрытой вкладке/документе и при dispose кадры отменяются. Пауза сохраняет работающую камеру; reduced motion вычисляет конечную позицию без видимой анимации. При >500 сохраняется навигационная агрегация, физика всех документов не запускается; drag раскрытого документа не включает бесконечный loop.

Зависимость d3-force оценивалась по официальному описанию cooling/stop/restart; для ограниченного среза выбран собственный небольшой solver без новых зависимостей, GPU или WebGL. O(n²) ограничен 500 узлами. Это приблизительная геометрия, не шкала cosine и не оценка качества embeddings.

Камера использует фактический SVG screen CTM и единый перевод между CSS- и мировыми координатами. Wheel нормализует deltaMode и ограничивает шаг; очередь инерции отсутствует, поэтому смена направления действует сразу. Ctrl/Meta-wheel (в том числе синтезируемый браузером pinch) не перехватывается картой и остаётся приложению. Физический trackpad отдельно не проверен. Fit, Focus, Back и Clear selection остаются разными действиями.

Подписи — отдельный DOM overlay в CSS-единицах, с native font token. Графический zoom не увеличивает текст; пользовательский Electron zoom продолжает действовать. Приоритет: выбранные, hover/focus, результаты поиска, затем остальные. Реальные экранные размеры, препятствия контролов/панелей/точек и уже размещённые подписи проверяются перед показом. Второстепенные названия сокращаются и скрываются при тесноте; полный путь доступен в панели/списке. Во время стабилизации второстепенные подписи скрыты, чтобы не мерцать; выбранные/hover сохраняются. Точки ради текста не передвигаются.

При переносе ItemView в popout `onWindowMigrated` пересоздаёт disposable renderer в новом ownerDocument/Window, сохраняя UI-физику и контекст. Согласия и tickets принадлежат прежним disposable review owners и не восстанавливаются при Back.

## Native референс и фикстура

Штатный Graph View и карта открываются рядом в настоящем Obsidian на одной synthetic fixture. Управление выполняется через native CDP input. Для drag штатного графа видимая круглая точка определяется по screenshot; недокументированные renderer-объекты, физические координаты Graph View, monkeypatch и закрытый код не используются. Снимки показывают также ограничения референса: длинные подписи у штатного графа могут перекрываться. Его поведение не принимается за гарантию читаемости.

Срез: 154 документа, 46 прямых тегов пяти буквальных фасетов; широкие группы 95/94/54/50/45/31, членства до восьми тегов, длинные названия, два `Cache.md` в разных папках и безтеговые документы. Unknown/stale проверяются отдельными обозначенными fault scenarios через реальный metadata adapter и index revision notification. Названия и тексты созданы синтетически. Настроенная личная таксономия не читалась. Большие наборы дополняются копиями существующего synthetic Lab; новый 1000-note corpus не генерируется.

Векторы искусственные deterministic. Они проверяют геометрию, cap, источники и маршрут UI, **не качество embedding-модели**. Для Apply/Undo только completion transport заменён локальным фиксированным JSON; validator, planner, exact review, writer, журнал и Undo настоящие. Файлы не восстанавливаются копированием в обход исполнителя. Платные/внешние запросы заблокированы в harness.

## Результаты и воспроизведение

Финальные результаты, hashes, source commit и native измерения добавляются после проверки frozen сборки. До этого текущий документ не является заявлением полного прохождения.

```bash
# Fresh disposable profile; never pass the original or installed TEST vault.
node scripts/map-visual-native.mjs /tmp/veynrel-workbench-v3-new 154 /absolute/path/to/frozen-build
# Larger copies reuse the existing synthetic Lab:
VEYNREL_LAB_ROOT=/absolute/path/to/synthetic-lab \
  node scripts/map-visual-native.mjs /tmp/veynrel-workbench-v3-large 500 /absolute/path/to/frozen-build
# 1000: honest aggregation + unchanged 500 unique eligible semantic cap.
```

Отдельные offline режимы: `V3_NO_INDEX=1`; `VEYNREL_THEME_DIR=/path/to/local/theme` копирует только theme.css/manifest в synthetic vault. В evidence не публикуются CSS сторонней темы, личные пути или пользовательские screenshots.

Не проверены физический mobile/touch/trackpad, озвучивание screen reader, все сторонние темы и реальная embedding quality. Ручная оценка формы/движения и полезности остаётся открытой. 60 FPS не обещается; измерения относятся к этой машине и указанному native окружению.

## Источники

- [Obsidian Graph View](https://help.obsidian.md/plugins/graph): документированные hover, wheel/keyboard pan/zoom, цветовые группы, text fade и force controls. Не источник предположений о внутренней реализации.
- [d3-force simulation](https://d3js.org/d3-force/simulation): контролируемое охлаждение и остановка; изменение переданных узлов — причина всегда отделять UI-копии от immutable snapshots.
- [W3C Use of Color](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color): цвет дополнен названиями, выделением и списком участников.
