# Support

Read the [user guide](docs/wiki/Home.md) and [troubleshooting](docs/wiki/Troubleshooting.md) first.

- Ask usage questions in [Discussions](https://github.com/zinverno/veynrel/discussions).
- Report reproducible defects with the [bug form](https://github.com/zinverno/veynrel/issues/new?template=bug.yml).
- Propose a specific user outcome with the feature form. Community recipe changes belong in [veynrel-recipes](https://github.com/zinverno/veynrel-recipes).

Include plugin/Obsidian/OS versions, the relevant optional Excalidraw version, exact steps, expected/actual behavior and a minimal synthetic note. Label controlled responses and untested claims. Redact secrets before creating evidence; prefer a new disposable fixture rather than screenshots of a private vault.

Do not post API keys, account/billing metadata, personal vaults, full settings files, raw private model responses or journals containing private note text. Preserve uncertain write evidence locally and stop repeating the action. There is no guaranteed response time. Security concerns follow [SECURITY.md](SECURITY.md).
